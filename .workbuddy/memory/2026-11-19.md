## MediaPipe Hands + Three.js 手势圣诞粒子树（从零搭建）

**目标**：粒子圣诞树 + 手势交互 + MP3 音乐驱动呼吸，三层解耦（形态/能量）。

**架构**（src/）：
- `ParticleTree.js`：26k 针叶粒子（自定义 ShaderMaterial，程序化针叶纹理 + 旋转 UV）、
  1500 光尘、190 螺旋彩灯、30 个 InstancedMesh 金属装饰球、LatheGeometry 树体、Sprite 树顶星。
- `GestureController.js`：MediaPipe HandLandmarker（本地 wasm + 模型），输出 palm/openness/pinch/palmUp，
  事件 burst / clap / tray。
- `AudioEngine.js` + `BeatDetector.js` + `BreathMapper.js`：分频段 FFT → 鼓点 → 亮度/Bloom/暖色。
- `InteractionRouter.js`：手势控形（scale/collapse/explode/swirl），音乐控能，相加后 clamp。
- `GiftRain.js`：掉落礼物 + 托盘接取 + 金色爆散。

**关键经验**：
1. 粒子"没有体积"的根因不是数量，而是缺伪光照 + 背面压暗。着色器里用径向法线做 lambert、
   按 hN 做高度衰减、按 p.z 做背面压暗（×0.32），体积感立刻出来。
2. 实心锥体会从粒子壳的低谷处穿出来，形成黑色横带 → 改用 LatheGeometry 跟随 `radiusAt()`
   分层曲线，并缩到 0.84 倍藏在壳内。
3. 加法混合会累积饱和度，光尘/雪花的亮度必须压到 0.5~0.9，否则整棵树糊成"雪球"。
4. 鼓点检测不能用单频段绝对阈值：频谱平滑会把一次底鼓拖成连续触发。
   改成 `score = low*0.7 + rms*0.9` + 最近 1s 均值/标准差自适应阈值 + 200ms 冷却 + 重新武装，
   60fps 合成信号下 BPM 估算准确（96→96）。
5. 预热条件不能写 `history.length > N`（帧率低时永远不满足），要改按时间 `now - startAt > 600`。

**踩坑**：jsdelivr 下载 wasm 会被截断（7.2MB vs 9.4MB），WebAssembly 报 "section extends past end"，
必须校验 Content-Length。所有依赖已本地化到 `vendor/`，断网可跑。

**运行**：`start.bat` 或 `python -m http.server 8123`，摄像头需 localhost/https。
`?debug` 暴露 `window.__app`。
